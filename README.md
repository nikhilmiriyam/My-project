# RideShare

RideShare is a professional full-stack ride-sharing application prototype developed to demonstrate role-based user experience design, secure onboarding flows, and deployment-ready web application architecture. The project highlights end-to-end frontend development, backend integration, and modern deployment practices suitable for portfolio presentation.

## Key Features
- Passenger and rider account workflows
- Role-based authentication and user experience
- Booking preview, confirmation, and reservation flow
- Dashboard, account management, booking history, sign-in, and sign-up interfaces
- Rider onboarding with official vehicle, license, and identity details
- Express-based backend serving the frontend for local development and cloud deployment

## Technology Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Deployment: Render, GitHub
- Data Handling: LocalStorage for demo persistence

## Setup Instructions
1. Install dependencies:
   - npm run install:all
2. Start the application locally:
   - npm run dev
3. Open the application in your browser using your Render deployment URL.
   - Example: https://rideshare.onrender.com

## Environment Configuration
Set the following environment variables for deployment or hosting:
- PORT
- HOST
- APP_NAME
- MONGO_URI

## Deployment
The project is configured for deployment on Render using a Node.js web service with GitHub integration.
